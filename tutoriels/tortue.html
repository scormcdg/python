Démarrer

Chaque programme commence par une seule ligne : from turtle import *. Ensuite, on écrit les commandes directement, sans t. devant, et on indente toujours de 4 espaces.

from turtle import *

color("blue")
forward(100)
left(90)
forward(100)

On tape le code dans l'éditeur, puis on clique sur Exécuter : la tortue dessine dans la zone de dessin. Elle part du centre (0, 0) et regarde vers la droite.

Trois règles du cours :

  • from turtle import * et rien d'autre (pas de import turtle, pas de Turtle() ni de Screen()).
  • Pas de t.forward(...) : on écrit forward(...).
  • Les blocs (for, def, if, while) sont indentés de 4 espaces exactement.

Les commandes done(), mainloop(), exitonclick(), setup() et title() sont acceptées mais ne font rien : inutile de les ajouter.

Les commandes de base

Cette version connaît les commandes ci-dessous ; les abréviations entre parenthèses font la même chose.

Commande Ce qu'elle fait
forward(d) (fd) avance de d pixels
backward(d) (back, bk) recule de d pixels
left(a) (lt) / right(a) (rt) tourne de a degrés à gauche / à droite
goto(x, y) (setpos, setposition) va au point (x, y)
setx(x) / sety(y) change seulement x ou y
setheading(a) (seth) regarde dans la direction a (0 = droite, 90 = haut)
home() retourne au centre, regarde à droite
circle(r) / circle(r, angle) / circle(r, angle, n) cercle de rayon r, arc d'angle donné, ou polygone à n côtés
penup() (pu, up) / pendown() (pd, down) lève / pose le stylo
width(e) (pensize) épaisseur du trait
dot(taille) / dot(taille, couleur) point rond
stamp() laisse l'empreinte de la tortue
write("texte") / write("texte", font=("Arial", 16, "normal")) écrit un texte
speed(v) vitesse de 1 (lent) à 10 ; speed(0) = le plus rapide
hideturtle() (ht) / showturtle() (st) cache / montre la tortue
shape("turtle"), shapesize(2) forme et taille de la tortue
clear() / reset() efface le dessin / efface et remet la tortue au centre
pos(), xcor(), ycor(), heading(), distance(x, y) donnent la position, l'angle, une distance

Pas disponibles ici : towards(), colormode(), les clics et touches (onscreenclick, onkey, listen), numinput()/textinput() et ontimer().

Les 4 façons d'écrire une couleur

Une couleur s'écrit de quatre façons ; toutes marchent dans color(), pencolor(), fillcolor(), bgcolor() et dot(). Il n'y a pas de colormode() : la tortue reconnaît seule l'échelle utilisée.

Façon Exemple À savoir
Nom anglais color("orange") entre guillemets ; en anglais seulement ("red", pas "rouge")
Code hexadécimal color("#ff8800") ou color("#f80") commence par # ; majuscules acceptées ("#FF8800")
Trois nombres de 0 à 1 color((1, 0.5, 0)) rouge, vert, bleu ; 1 = au maximum, 0.5 = à moitié
Trois nombres de 0 à 255 color((255, 128, 0)) rouge, vert, bleu ; 255 = au maximum

Les quatre exemples donnent un orange (presque le même : "orange" est un tout petit peu plus jaune).

Les noms

Quelques noms utiles :

"black" "white" "gray" "red" "orange" "yellow" "green" "darkgreen" "blue" "navy" "skyblue" "purple" "pink" "brown" "gold" "tomato" "turquoise" "lightgreen"

Beaucoup d'autres noms anglais existent.

Le code hexadécimal

#rrggbb donne la quantité de rouge, de vert et de bleu, chacune avec deux chiffres de 00 (rien) à ff (tout). Ainsi "#ff0000" est rouge, "#00ff00" vert, "#000000" noir et "#ffffff" blanc. La forme courte #rgb double chaque chiffre : "#f80" = "#ff8800".

Les trois nombres

On met les trois nombres entre parenthèses, séparés par des virgules : (rouge, vert, bleu). Si un nombre dépasse 1, la tortue lit l'échelle 0–255 ; sinon, elle lit l'échelle 0–1.

  • (1, 0.5, 0) : 1 = 255 et 0.5 ≈ 128, donc c'est le même orange que (255, 128, 0).
  • (1, 1, 1) est lu de 0 à 1 : c'est du blanc, pas un noir presque total.
  • Pour du gris : trois nombres égaux, par exemple (0.5, 0.5, 0.5) ou (128, 128, 128).

Astuce : avec l'échelle 0–1, on peut faire varier une couleur dans une boucle.

from turtle import *

speed(0)
for i in range(10):
    color((i / 10, 0, 1 - i / 10))
    forward(30)

Trait, remplissage et fond

La tortue a deux couleurs : celle du trait et celle du remplissage. color() peut changer les deux d'un coup ; pencolor() et fillcolor() en changent une seule.

Commande Trait Remplissage
color("red") rouge rouge
color("red", "blue") rouge bleu
pencolor("red") rouge inchangé
fillcolor("blue") inchangé bleu
bgcolor("lightyellow") — — (colore le fond de la zone de dessin)

On peut mélanger les façons d'écrire : color("#ff8800", "red") ou color((0, 0, 1), "yellow") marchent.

Remplir une forme

On place le dessin de la forme entre begin_fill() et end_fill(). La forme se remplit au moment de end_fill(), avec la couleur de remplissage choisie avant.

from turtle import *

color("darkgreen", "lightgreen")
begin_fill()
for i in range(4):
    forward(100)
    left(90)
end_fill()

Ce programme dessine un carré au bord vert foncé, rempli de vert clair. Si la forme n'est pas fermée, end_fill() la ferme tout droit vers le point de départ.

Le fond

bgcolor() colore tout le fond, à n'importe quel moment du programme. Les dessins restent par-dessus.

Un point de couleur

dot(20, "red") dessine un disque rouge de 20 pixels, sans changer la couleur du stylo. Sans couleur, dot(20) utilise la couleur du trait.

Exemples complets à essayer

Chaque exemple utilise une autre façon d'écrire les couleurs. Copiez-le, exécutez-le, puis changez les couleurs.

1. Un soleil (noms)

from turtle import *

bgcolor("skyblue")
speed(0)
color("orange", "yellow")
begin_fill()
circle(60)
end_fill()

2. Trois carrés (codes hexadécimaux)

from turtle import *

def carre(cote, couleur):
    fillcolor(couleur)
    begin_fill()
    for i in range(4):
        forward(cote)
        left(90)
    end_fill()

pencolor("#333333")
carre(60, "#e63946")
forward(80)
carre(60, "#f4a261")
forward(80)
carre(60, "#2a9d8f")

3. Un dégradé (nombres de 0 à 1)

from turtle import *

speed(0)
width(8)
penup()
goto(-200, 0)
pendown()
for i in range(20):
    pencolor((i / 20, 0.2, 1 - i / 20))
    forward(20)

La ligne passe du bleu au rouge : le rouge augmente pendant que le bleu diminue.

4. Des points (nombres de 0 à 255)

from turtle import *

speed(0)
hideturtle()
penup()
for i in range(6):
    dot(40, (255, 40 * i, 0))
    forward(50)

Les points vont du rouge au jaune, car le vert passe de 0 à 200.

5. Une fleur (trait et remplissage différents)

from turtle import *

speed(0)
color("purple", "pink")
for i in range(6):
    begin_fill()
    circle(50, 60)
    left(120)
    circle(50, 60)
    end_fill()
    left(60)
hideturtle()

Erreurs fréquentes et messages

Voici les erreurs de couleur les plus courantes, avec le message exact affiché par cette version.

Code écrit Problème Message affiché Correction
color(red) guillemets oubliés Pour une couleur, il faut des guillemets (ligne 2) : color("red"). color("red")
color("rouge") nom en français Couleur invalide dans color() : utilisez par exemple color("red") ou color("#ff8800") (ligne 2). color("red")
color("ff8800") # oublié même message « Couleur invalide » color("#ff8800")
color("red", "bleu") 2e couleur en français même message « Couleur invalide » color("red", "blue")
color("red", "blue", "green") trois couleurs même message « Couleur invalide » une ou deux couleurs seulement
color((255, 128)) deux nombres au lieu de trois même message « Couleur invalide » color((255, 128, 0))
Color("red") majuscule La commande « Color » n'existe pas (ligne 2). Vouliez-vous écrire « color » ? color("red")
colormode(255) commande absente de cette version La commande « colormode » n'existe pas (ligne 2)… supprimer la ligne : l'échelle est reconnue seule
begin_fill() sans end_fill() remplissage jamais terminé aucun message, la forme reste vide ajouter end_fill() après la forme

Le numéro de ligne du message indique où chercher. Une forme qui reste vide sans message vient presque toujours d'un end_fill() oublié ou mal indenté (dans la boucle au lieu d'après).

Aide-mémoire

from turtle import *

# 4 façons d'écrire un orange
color("orange")          # nom anglais, entre guillemets
color("#ff8800")         # code hexadécimal, avec #
color((1, 0.5, 0))       # rouge, vert, bleu de 0 à 1
color((255, 128, 0))     # rouge, vert, bleu de 0 à 255

# trait et remplissage
color("red")             # trait ET remplissage rouges
color("red", "blue")     # trait rouge, remplissage bleu
pencolor("red")          # trait seulement
fillcolor("blue")        # remplissage seulement
bgcolor("lightyellow")   # fond

# remplir une forme
begin_fill()
circle(50)
end_fill()

# point de couleur
dot(20, "red")
  • Toujours des guillemets autour d'un nom ou d'un code #.
  • Noms en anglais seulement.
  • Pas de colormode() : l'échelle 0–1 ou 0–255 est reconnue seule.
  • speed(0) = le plus rapide.
